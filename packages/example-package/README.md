# example-package

## About This Package

This is a placeholder example package included with your monorepo setup. It demonstrates the basic structure and configuration for packages in this repository.

## Next Steps

If you are starting a new project, you likely do not need this example package. You can safely remove it and generate a new package tailored to your needs.

### How to Remove and Generate a New Package

1. Delete the `example-package` folder:
   - `packages/example-package`
2. Run the following command to generate a new package using the monorepo generator:

   ```sh
   pnpm run turbo:gen:init
   ```

Follow the prompts to create a package that fits your project requirements.
